# Security Policy

## Reporting a Vulnerability

This project contains writing skill templates and documentation. It does not contain executable code that poses traditional security risks.

However, if you find:

- **Malicious content** in any skill file
- **Misleading advice** that could cause harm
- **Plagiarized content** from copyrighted sources

Please report it by emailing the maintainers or opening a private security advisory on GitHub.

## Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial assessment:** Within 1 week
- **Resolution:** Within 2 weeks (depending on complexity)

## Scope

This policy covers all files in the repository, including:
- Skill template files
- Documentation
- CI/CD configurations

Thank you for helping keep this project safe and trustworthy.
