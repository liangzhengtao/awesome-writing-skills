## 🎯 O Problema

Você se senta para escrever. O cursor pisca. Os minutos passam. Você escreve uma frase, apaga, escreve de novo.

**Parece familiar?** Seja um post de blog, e-mail de vendas, resumo de pesquisa ou relatório empresarial — a parte mais difícil é saber *como* estruturar o que você quer dizer.

## ✅ A Solução

12 habilidades de escrita com IA comprovadas, cada uma um manual completo com:

- **Quando Usar** — gatilhos claros para quando cada habilidade se aplica
- **Estrutura de Escrita** — passo a passo a seguir
- **Templates** — pontos de partida para preencher
- **Palavras e Frases de Impacto** — linguagem que funciona
- **Erros Comuns** — armadilhas a evitar
- **Exemplos Antes/Depois** — veja a transformação

## 🚀 Início Rápido

### Para Assistentes de IA (Claude, ChatGPT, Kimi, etc.)

1. **Copie** o conteúdo do arquivo de habilidade que corresponde à sua tarefa
2. **Cole** como instruções de sistema ou contexto
3. **Forneça** seu tópico, público e requisitos específicos
4. **Obtenha** uma peça de escrita polida e estruturada

### Para Escritores

1. **Navegue** pela tabela de habilidades acima
2. **Abra** o arquivo de habilidade relevante
3. **Siga** a estrutura passo a passo
4. **Use** os templates como pontos de partida

## 🔄 Antes / Depois

### Antes: Uma Página em Branco

```
I need to write a blog post about productivity tips.

... (staring at cursor for 20 minutes) ...
```

### Depois: Usando [SEO Blog Post](skills/博客写作/seo-blog-post.md)

```markdown
# 15 Productivity Tips That Actually Work (Backed by Science)

**Meta Description:** Discover 15 proven productivity tips used by top performers.
Learn time management, focus techniques, and habit-building strategies.

## Introduction (Hook)
"80% of people feel overwhelmed by their workload." — American Psychological Association

You've read every productivity article out there. Tried the Pomodoro Technique.
Downloaded three different apps. Yet here you are, still drowning in tasks.

The problem isn't lack of tips — it's using the *right* tips for *your* situation.

## Tip 1: The Two-Minute Rule
[Framework continues with structured, SEO-optimized content...]
```

**A diferença?** Uma estrutura clara elimina a fadiga decisória e fornece uma estrutura comprovada para preencher — não uma página em branco para preencher do zero.
