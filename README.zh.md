## 🎯 问题所在

你坐下来准备写作。光标闪烁着。时间一分一秒过去。你写了一句话，删掉，再写一遍。

**听起来很熟悉？** 无论是博客文章、销售邮件、研究摘要还是商业报告——最难的部分是知道*如何*组织你想表达的内容。

## ✅ 解决方案

12 个经过实战检验的 AI 写作技能，每个都是完整的写作手册，包含：

- **使用场景** — 每个技能适用的明确触发条件
- **写作框架** — 可以遵循的分步结构
- **模板** — 填空式的起始模板
- **强力词汇与短语** — 有效的语言表达
- **常见错误** — 需要避免的陷阱
- **前后对比示例** — 直观感受变化

## 🚀 快速开始

### AI 助手用户（Claude、ChatGPT、Kimi 等）

1. **复制**与你任务匹配的技能文件内容
2. **粘贴**为系统指令或上下文
3. **提供**你的具体主题、受众和需求
4. **获得**一篇结构清晰、质量上乘的文章

### 写作者

1. **浏览**上方的技能表格
2. **打开**相关的技能文件
3. **按照**分步框架操作
4. **使用**模板作为起点

## 🔄 前后对比

### 使用前：空白页面

```
我需要写一篇关于提高生产力的博客文章。

……（盯着光标看了 20 分钟）……
```

### 使用后：使用 [SEO 博客文章](skills/博客写作/seo-blog-post.md) 技能

```markdown
# 15 个真正有效的生产力技巧（有科学依据）

**元描述：** 发现 15 个顶尖表现者使用的经过验证的生产力技巧。
学习时间管理、专注技巧和习惯养成策略。

## 引言（钩子）
"80% 的人觉得工作量不堪重负。" — 美国心理学会

你已经读过所有关于生产力的文章了。试过番茄工作法。
下载了三个不同的应用。然而你还是在这里，被任务淹没。

问题不在于缺少技巧——而在于针对*你的*情况使用*正确的*技巧。

## 技巧 1：两分钟法则
[框架继续以结构化、SEO 优化的内容展开……]
```

**区别在哪？** 清晰的框架消除了决策疲劳，给你一个经过验证的结构来填充——而不是一张需要从头开始填写的白纸。
