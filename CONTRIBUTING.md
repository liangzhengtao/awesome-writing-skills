# Contributing to Awesome Writing Skills

Thank you for your interest in contributing! This project thrives on community input.

## Ways to Contribute

### 1. Add a New Writing Skill
- Create a new `.md` file in the appropriate `skills/` subdirectory
- Follow the existing skill file structure (see below)
- Submit a pull request

### 2. Improve Existing Skills
- Fix errors, add examples, or improve templates
- Keep changes focused — one improvement per PR

### 3. Translations
- Translate skill files to other languages
- Use the same filename with a language suffix (e.g., `seo-blog-post.zh.md`)

### 4. Report Issues
- Use the GitHub issue templates
- Include specific examples when reporting problems

## Skill File Structure

Every skill file must follow this structure:

```markdown
# Skill Name

> One-line description

## When to Use
- Clear trigger conditions

## Writing Framework
Step-by-step instructions

## Templates
Fill-in-the-blank examples

## Power Words and Phrases
Categorized word lists

## Common Mistakes to Avoid
What NOT to do, with explanations

## Before/After Examples
Side-by-side transformations
```

## Style Guidelines

- Write in clear, actionable language
- Include concrete examples, not abstract advice
- Keep templates practical — they should be immediately usable
- Use both English and Chinese where appropriate
- Test your templates by actually using them

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b add-new-skill`)
3. Make your changes
4. Run the validation checks (`npm test` if applicable)
5. Submit a pull request with a clear description

## Code of Conduct

Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.

## Questions?

Open a discussion in the GitHub Discussions tab or file an issue.
