## 🎯 Das Problem

Sie setzen sich zum Schreiben. Der Cursor blinkt. Minuten vergehen. Sie schreiben einen Satz, löschen ihn, schreiben ihn erneut.

**Kommt Ihnen das bekannt vor?** Ob Blog-Post, Verkaufs-E-Mail, Forschungsreferat oder Geschäftsbericht — das Schwierigste ist zu wissen, *wie* man strukturiert, was man sagen möchte.

## ✅ Die Lösung

12 bewährte KI-Schreibskills, jeder ein komplettes Handbuch mit:

- **Wann verwenden** — klare Auslöser für die Anwendung jedes Skills
- **Schreibrahmen** — Schritt-für-Schritt-Struktur
- **Vorlagen** — Ausfüllvorlagen als Startpunkte
- **Kraftvolle Wörter und Phrasen** — wirksame Sprache
- **Häufige Fehler** — Fallstricke, die es zu vermeiden gilt
- **Vorher/Nachher-Beispiele** — sehen Sie die Verwandlung

## 🚀 Schnellstart

### Für KI-Assistenten (Claude, ChatGPT, Kimi usw.)

1. **Kopieren** Sie den Inhalt der Skill-Datei, die zu Ihrer Aufgabe passt
2. **Einfügen** als Systemanweisungen oder Kontext
3. **Angeben** Ihres spezifischen Themas, Publikums und der Anforderungen
4. **Erhalten** Sie einen polierten, strukturierten Text

### Für Autoren

1. **Durchsuchen** Sie die Skills-Tabelle oben
2. **Öffnen** Sie die relevante Skill-Datei
3. **Folgen** Sie dem Schritt-für-Schritt-Rahmen
4. **Verwenden** Sie die Vorlagen als Startpunkte

## 🔄 Vorher / Nachher

### Vorher: Eine leere Seite

```
I need to write a blog post about productivity tips.

... (staring at cursor for 20 minutes) ...
```

### Nachher: Mit [SEO Blog Post](skills/博客写作/seo-blog-post.md)

```markdown
# 15 Productivity Tips That Actually Work (Backed by Science)

**Meta Description:** Discover 15 proven productivity tips used by top performers.
Learn time management, focus techniques, and habit-building strategies.

## Introduction (Hook)
"80% of people feel overwhelmed by their workload." — American Psychological Association

You've read every productivity article out there. Tried the Pomodoro Technique.
Downloaded three different apps. Yet here you are, still drowning in tasks.

The problem isn't lack of tips — it's using the *right* tips for *your* situation.

## Tip 1: The Two-Minute Rule
[Framework continues with structured, SEO-optimized content...]
```

**Der Unterschied?** Ein klarer Rahmen beseitigt Entscheidungserschöpfung und gibt Ihnen eine bewährte Struktur zum Ausfüllen — keine leere Seite zum Füllen von Grund auf.
